## How to Setup

The website can be viewed locally by running the following commands:

### 1. Clone the Repository

```
git clone https://github.com/Tyelk/__The_Phoenix_Project__.git
cd __The_Phoenix_Project__
```

### 2. Install Dependencies

```
npm install
```

### 3. Build Project

```
npm run build
```

### 3. Run Preview

```terminal
npm run preview
```

## Other Commands

The app can alternatively be run with the following command:

### Run Project

```
npm run dev
```
